# Contributing to HR Management Pro Suite

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/HR-Management-Pro-Suite-Odoo.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feat/your-feature
   ```

## Development Setup

- Odoo 17.0 Community Edition
- Python 3.10+
- PostgreSQL 14+

## Code Style

- **Python**: PEP 8, 4 spaces indentation, snake_case for fields/methods, CamelCase for classes
- **XML**: 4 spaces indentation, use Odoo naming conventions
- **Commits**: `[hr_management_pro] TYPE: Summary`
  - Types: `FIX`, `FEAT`, `REFACTOR`, `DOCS`, `TEST`, `STYLE`

## Pull Request Process

1. Ensure your code follows the style guidelines above
2. Update documentation if needed
3. Test your changes with Odoo 17
4. Submit a PR with a clear description

## Reporting Issues

Open an issue on GitHub with:
- Steps to reproduce
- Expected vs actual behavior
- Odoo version and environment details
