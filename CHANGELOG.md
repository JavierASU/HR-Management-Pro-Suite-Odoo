# Changelog

All notable changes to HR Management Pro Suite will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [17.0.1.1.0] - 2026-03-27

### Added
- Employee profile extension with seniority, contract type, work modality, and performance fields
- Internal request model with automatic sequence numbering
- Multi-level approval workflow (Draft > Submitted > Manager > HR > Done)
- Dashboard views with smart filters (pending, awaiting HR, approved this month)
- Mass approval wizard for managers and HR administrators
- QWeb PDF report with employee and approver signatures
- Role-based security: HR Pro User, HR Pro Manager, HR Pro Admin
- Record rules for data access control per role
- Full mail.thread integration with field tracking
- Custom CSS styling for backend views

## [17.0.1.0.0] - 2026-03-22

### Added
- Initial module structure
- Basic models and views scaffold
